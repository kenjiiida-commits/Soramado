# そらみ窓 説明書

そらみ窓は、地球のそばから「観測できる宇宙の果て」まで、宇宙を自由に旅できるソフトです。
惑星や月は、指定した日時の実際の位置に表示されます。

---

## 1. 画面の見かた

- **まん中**：宇宙の3D表示です。
- **上のツールバー**：見る天体、地上モード、録画、時間、表示の調整を行います。
- **右の「解説」パネル**：選んでいる天体の説明が出ます。「表示」メニューで出し入れできます。
- **下の欄**：選んでいる天体の大きさ・距離などが出ます。
- **左下**：画面の横幅がどれくらいの長さか（km・AU・光年）が出ます。

> **AU（天文単位）**：地球と太陽のあいだの平均距離（約1億5千万km）。
> **光年**：光が1年かかって進む距離（約9兆5千億km、約6万3千AU）。

**英語の表示**：「表示」→「言語 / Language」で English を選び、そらみ窓を起動し直すと、メニュー・ボタン・
天体や星座の名前・下の欄・天文現象の一覧などが英語になります。天体の解説文・ツアーの字幕・この説明書は、今は日本語のままです。

---

## 2. 基本の操作

| 操作 | 動き |
|---|---|
| 左ドラッグ | 視点を回す |
| ホイール／右ドラッグ | 近づく・離れる |
| ダブルクリック | 惑星・銀河・探査機へ飛んでいく／恒星の情報を見る |
| スペース | 時間を止める・動かす |
| ＋／− | 近づく・離れる |
| F1 | この説明書 |
| F11 | 全画面表示 |
| Ctrl+S | 画面を画像で保存 |
| Ctrl+R | 録画の開始・停止 |
| Ctrl+F | 天体を探す（星座・星雲・星団・小惑星・系外惑星） |
| Ctrl+E | 日食・月食の一覧 |
| Esc | ツアーを終わる |

### 見る天体
ツールバー左の「見る天体」で選ぶと、その天体まで飛んでいきます。並び順は次のとおりです。

1. 太陽・惑星・月（衛星は親の惑星の下に字下げ）
2. 準惑星・小惑星・彗星
3. 探査機（🛰）
4. 星雲・星団（✦。ほかの星雲・星団は、画面の名前をダブルクリック）
5. 銀河
6. 観測できる宇宙の果て

「全体を見る」を押すと、太陽系全体が見える位置に戻ります。

### 時間
- 「⏸ 停止／▶ 再生」で時間を止めたり動かしたりします。
- 速さは「実時間」から「1年/秒」まで選べます。「逆再生」で過去へ進みます。
- 日時の欄に直接入力することもできます。「現在時刻」で今に戻ります。
- 惑星の位置は 1800〜2050年でもっとも正確です。この範囲の外では、右下に注意が出ます。

### 惑星の大きさ
実際の大きさ（×1）では、遠くから見ると惑星は点にしか見えません。「惑星の大きさ」のつまみで、最大1000倍まで大きく描けます（太陽は最大10倍）。

### 星の数
何等星まで表示するかを変えます。肉眼で見えるのは6.5等くらいまでです。

## 3. 宇宙を旅する

ホイールでどこまでも引いていくと、宇宙の大きさを順番に体験できます。

1. **太陽系**（数十AU）：惑星の軌道、準惑星、彗星、探査機の航路
2. **近くの恒星**（数十光年）：太陽も、ほかの星と同じ一つの星に見えてきます
3. **星雲・星団**（数百〜数万光年）：オリオン大星雲、すばる、ヘルクレス座球状星団など約90個（形は模式図）
4. **天の川銀河**（数千〜10万光年）：わたしたちの銀河の渦巻き（模式図）
5. **近くの銀河**（数百万光年）：マゼラン雲、アンドロメダ銀河など
6. **銀河の世界**（数億光年）：実在の銀河 約1万個。おとめ座銀河団などの集まり
7. **宇宙の果て**（数百億光年）：宇宙マイクロ波背景放射の球（模式図）、クエーサー

---

## 4. 地上から見る（プラネタリウム）

「🔭 地上から見る」を押すと、観測地に立って空を見上げる表示になります。もう一度押すと（「🚀 宇宙へ戻る」）元に戻ります。

- **観測地**：札幌・仙台・東京・三鷹・名古屋・大阪・広島・福岡・那覇から選ぶか、「緯度・経度を入力…」で追加します。
- **左ドラッグ**で見る方向、**ホイール**で視野（120度〜0.1度）を変えます。視野をしぼると、望遠鏡のように月の満ち欠けや木星の衛星が見えます。
- 太陽の高さによって、昼の青空・夕焼け・薄明・夜空に変わります。昼は星が見えません。
- 「見る天体」で惑星や月を選ぶと、その方向を向きます。

---

## 5. 星座の解説

星座の名前を**ダブルクリック**すると、その星座の線が明るくなり、解説パネルに見ごろ・見つけ方・神話や名前の由来と、おもな星が出ます（88星座すべて）。ほかの場所をダブルクリックすると選択が外れます。
**Ctrl+F** で「オリオン」のように名前を入れても探せます（地上モードでは、その星座の方を向きます）。

---

## 6. 惑星の衛星

「見る天体」では、惑星のすぐ下に、その惑星の衛星が惑星に近い順に並んでいます。

- **木星**：ガリレオ衛星（イオ・エウロパ・ガニメデ・カリスト）のほか、内側の小さな衛星（メティス・アドラステア・アマルテア・テーベ）と、遠くを回る不規則衛星（ヒマリア・エララ・パシファエ・シノーペなど）
- **土星**：大きな衛星のほか、環のすき間を回るパン、F環の羊飼い衛星プロメテウスとパンドラ、軌道を入れかえ合うヤヌスとエピメテウス、テティスやディオネと同じ軌道を回るトロヤ衛星、逆向きに回るフェーベなど
- **天王星**：環（ε環など細く暗い環）と、内側の小さな衛星（パック、ポーシャなど10個）、不規則衛星（シコラクス、キャリバン）
- **海王星**：環（アダムズ環など）と、内側の衛星（プロテウス、ラリッサなど7個）、とても細長い軌道のネレイド、ハリメデ
- 「惑星の大きさ」で惑星を拡大しているときは、拡大した惑星に埋もれてしまう内側の小さな衛星は表示しません。

---

### 大気の効果（地上モード）

地上から見るときは、空気の効果を入れて、本物の空に近く見えるようにしています。
「表示」→「大気の効果」で、切ったり入れたりできます。

- **浮き上がり（大気差）**：空気で光が曲がるため、地平線の近くの天体は少し高く見えます（地平線で約0.6°。太陽や月の大きさくらい）。沈む太陽が少しつぶれて見えるのもこのためです。
- **減光**：地平線に近いほど空気の層を長く通るので、星や月や太陽は暗く、赤っぽくなります。
- **空の色**：昼の青空は地平線に近いほど白っぽく、太陽のまわりは明るくなります。夕焼け・朝焼け、薄明の空の色の変わり方、太陽と反対側の地平線に見える「地球の影」とその上のピンクの帯（ビーナスの帯）も表します。

## 7. 天文現象（日食・月食・流星群・惑星の接近・人工衛星）

### 今夜の空ガイド（Ctrl+G）

「天文現象」→「今夜の空ガイド」で、観測地で今夜何が見えるかを1枚にまとめて出します。

- 日の入り・暗くなる時刻・日の出、月の形と月の出・月の入り（明るい月が出ている夜は、そのことも書きます）
- 見える惑星と、見える時間・いちばん高くなる時刻と方角
- 夜9時ごろ高く見える星座
- 今夜見える人工衛星（ISS など。人工衛星のデータをダウンロードしたとき）
- 流星群の見ごろ、これから1週間の惑星・月の接近、1か月以内の日食・月食

「［空を見る］」を押すと、そのときの空を地上モードで見られます。「◀ 前の夜」「次の夜 ▶」で、ほかの夜も調べられます。
「そらみ窓を起動したときに、今夜の空ガイドを出す」にチェックを入れると、起動するたびに出ます。

### 日食・月食

「天文現象」→「日食・月食…」（Ctrl+E）で、これから15年の日食・月食の一覧が出ます。

- 日時は、地球全体で食がいちばん大きくなるときです。観測地（ツールバーで選んだ場所）での見え方も出ます。見えるものは緑の字になります。
- 「**宇宙から見る**」：日食は太陽の側から地球を見て、地球に落ちた月の影（黒っぽい丸）を、月食は地球の影に入って赤黒くなった月を見ます。
- 「**地上から見る**」：観測地から太陽（日食）や月（月食）を見上げます。▶ 再生で、1分/秒で食が進みます。皆既日食では空が暗くなって星が見えてきます。
- 影の位置を正しく見せるため、「惑星の大きさ」は実際の大きさ（×1）に戻ります。
- 時刻は数分ずれることがあります。
- **太陽を直接見ると目を傷めます。本物の日食は、必ず日食グラスなどで観察してください。**

### 流星群
「天文現象」→「流星群…」で、これから1年の流星群の一覧が出ます。極大の日時、観測地で見やすい時刻、見える数の目安、月明かりの条件がわかります。
「地上から見る」を押すと、その時刻の空で放射点の方を向き、**流星が流れます**（流れる数は実際の約10倍に増やしています。地上モードで流星群の活動期間なら、いつでも流れます）。流星を止めたいときは「天文現象」→「地上モードで流星を流す」を外します。

### 人工衛星（ISS など）
「ファイル」→「人工衛星のデータ（ISS など）をダウンロード…」で、CelesTrak から人工衛星の軌道のデータを読み込みます（数十KB）。
- 地球の近くまで寄ると、国際宇宙ステーション（ISS）・中国宇宙ステーション（天宮）・ハッブル宇宙望遠鏡などが地球のまわりを回ります。名前をダブルクリックすると、その衛星を追いかけ、1周ぶんの軌道が出ます。
- 「天文現象」→「人工衛星（ISS など）が見える時刻…」で、これから10日に観測地の空を横切る時刻と方角がわかります。「見える」は、空が暗く、衛星に太陽の光が当たっているときです。「地上から見る」で、そのときの空を実時間で見られます。
- 軌道のデータは数日で古くなります。1週間より古いと注意が出るので、ダウンロードし直してください。

### 惑星・月の接近と見ごろ
「天文現象」→「惑星・月の接近と見ごろ…」で、惑星どうしや月と惑星の接近、外惑星の衝（一晩中見える見ごろ）、水星・金星の最大離角（夕方・明け方に見やすい）の一覧が出ます。「地上から見る」で、観測地でいちばん見やすい時刻の空を出します。

---

### 星座の形の変化（Ctrl+Y）

「表示」→「星座の形の変化（星の動き）」で、星の位置だけを20万年前から20万年後まで動かせます。
星は1つ1つがそれぞれの向きと速さで動いているので、何万年もたつと星座の形が変わります。

- つまみを動かすか、「未来へ動かす ▶」「◀ 過去へ動かす」で、星が動いていくところを見られます。
- 星座線も、星といっしょに動きます。明るい星の動いた跡は、だいだい色の線で出ます。
- 「見る星座」で選んで「地上から見る」を押すと、その星座が夜10時ごろ高く見える日の空を出します。
- 星はまっすぐ同じ速さで動くとして計算しています（HYG データベースの空間速度）。何万年も先は目安です。
- 動くのは星だけで、惑星の位置や時計、地球の歳差（地軸の向き）は変わりません。

## 8. ツアー

「ツアー」メニューから選ぶと、字幕つきで自動的に案内します。

- **太陽系めぐり**：太陽から冥王星まで
- **宇宙の大きさ**：地球から観測できる宇宙の果てまで
- **今夜の星空**：観測地で、その日の夜9時に見える惑星と月
- **探査機の旅**：ボイジャー、ニュー・ホライズンズ、はやぶさ、はやぶさ2
- **小惑星の世界**：小惑星帯、ケレス、ベスタ、トロヤ群、ヒルダ群、地球に近い小惑星、イトカワ、リュウグウ、アポフィス、太陽系外縁天体、ハレー彗星（小惑星・彗星のデータをダウンロードしておくと、たくさんの小惑星も見えます）
- **星の一生**：オリオン大星雲・わし星雲（誕生）→ すばる・ヒアデス星団 → 太陽 → 環状星雲・あれい状星雲（太陽くらいの星の最期）→ かに星雲・網状星雲（重い星の最期）→ ヘルクレス座球状星団（いちばん古い星）
- **宇宙の歴史**：宇宙の果て（宇宙マイクロ波背景放射、138億年前）→ 最初の星と銀河 → 宇宙の大規模構造 → 天の川銀河 → 古い星・超新星 → 太陽と太陽系の誕生 → 月の誕生 → 地球と生命 → 加速する宇宙の膨張
- **系外惑星の世界**：ペガスス座51番星、プロキシマ・ケンタウリ、TRAPPIST-1、ケプラー452、ケプラー90、HR 8799（系外惑星のデータが必要です）

「◀ 前」「次 ▶」で場面を行き来し、「終了」か Esc で終わります。

## 9. 画像・動画の保存

- **Ctrl+S**：今の画面を画像（PNG）で「ピクチャ/Soramado」に保存します。
- **⏺ 録画**（Ctrl+R）：動画（MP4）で「ビデオ/Soramado」に保存します。録画中は1コマずつ描くので、パソコンが遅くても動画はなめらかになります。
- **ツアー → ツアーを動画にする**：ツアー全体を1本の動画にします。
- 録画には ffmpeg が必要です（`sudo apt install ffmpeg`）。

## 10. ダウンロードして使うデータ

「ファイル」メニューから、次のデータを追加できます（どれも任意です）。

- **惑星の画像**（約10MB）：Solar System Scope の画像（CC BY 4.0）。ダウンロードしない場合は簡易的な模様で表示します。
- **クエーサーのデータ**（約20〜40MB）：SDSS のクエーサー約75万個。数億光年より遠くまで引くと見えます。

- **小惑星・彗星のデータ**（約60〜90MB）：NASA JPL の軌道要素の表。番号の付いた小惑星 約80万個と彗星 約4千個を、なかまごとに色分けして表示します。
  - 橙＝地球に近い小惑星、灰白＝小惑星帯、黄＝ヒルダ群、緑＝木星のトロヤ群、紫＝ケンタウルス族、青＝太陽系外縁天体、水色＝彗星
  - 点をダブルクリックすると、その天体の名前と軌道が出ます。
  - **Ctrl+F**（「表示」→「天体を探す」）で、名前（英語）や番号から探して飛んでいけます。例：Itokawa、Ryugu、433、Halley
  - ダウンロードがうまくいかないときは、ブラウザーで ELEMENTS.NUMBR.gz と ELEMENTS.COMET をダウンロードして、「ファイル」→「小惑星・彗星のデータを手元のファイルから読み込む」で2つとも選んでください。

- **系外惑星のデータ**（約1〜2MB）：NASA Exoplanet Archive の表。これまでに見つかった、太陽系の外の惑星（約6千個）です。
  - 系外惑星を持つ恒星に**緑の丸**が付きます（太陽系の近くでは約300光年までの恒星）。
  - 緑の丸をダブルクリックすると、その惑星系へ飛んでいきます。恒星のまわりを惑星が回り、解説パネルに惑星の一覧（大きさ・重さ・公転周期・発見の年と方法）が出ます。
  - **緑の軌道**は、ハビタブルゾーン（水が液体でいられるかもしれない範囲）の中の惑星です。
  - 惑星の軌道の向きと、軌道上の位置は模式です（地球から見て真横を向いているように描いています）。
  - Ctrl+F で恒星や惑星の名前から探せます。例：TRAPPIST-1、Proxima Cen、51 Peg、Kepler-452
  - うまくダウンロードできないときは、ブラウザーで表を CSV で保存して、「ファイル」→「系外惑星のデータを手元のファイル（CSV）から読み込む」で選んでください。

- **人工衛星のデータ**（数十KB）：CelesTrak の軌道要素。くわしくは「7. 天文現象」の「人工衛星」を見てください。

- **星雲・銀河の写真**（約80MB）：DSS2 color（パロマー天文台などの写真乾板をデジタル化した全天写真）。
  ESA（ESASky）が配信している全天の写真から、星雲・星団・銀河 約95個のまわりを切り出して保存します。
  - 星雲・銀河を**地球の側から見ると本物の写真**、横や裏に回ると粒の**模式図**に切り替わります。
  - 環状星雲のように小さすぎるものは、写真では白くつぶれるので模式図のままです。
  - 「表示」→「星雲・銀河を写真で表示」で、写真を出さないようにもできます。
  - 途中で失敗したものは、もう一度ダウンロードすると足りない分だけ取りに行きます。

- **天の川の写真**（約3MB）：ESA の Gaia 衛星が測った約17億個の星の光から作られた全天の地図。
  太陽系の近くから見た空と、「地上から見る」の夜空に天の川が出ます（昼や薄明のときは見えません）。
  太陽系から数千光年離れると、空の見え方が変わるので消え、模式図の天の川銀河に切り替わります。
  「表示」→「天の川を写真で表示」で、出さないようにもできます。
  「表示」→「天の川の明るさ」で、控えめ（暗い山の上の見え方）・ふつう・明るめ・とても明るい から選べます。

ダウンロードしたデータは `~/.local/share/soramado/` に保存されます。

## 11. 精度について

- 惑星・月・衛星・恒星の位置は、天文計算の専門ライブラリと比べて確かめています（惑星は0.2度以内、恒星は0.01度程度）。
- 小さな衛星（木星・土星・天王星・海王星）とトリトンは、NASA JPL Horizons の2026年11月の軌道要素から計算しています。2026年から離れるほど、おおよその位置になります。
- 準惑星・小惑星・彗星・探査機の位置は、おおよそのものです（小惑星・彗星は惑星の引力による変化を計算していません）。
- 天の川銀河やほかの銀河の形、宇宙マイクロ波背景放射の模様は**模式図**です（本物の写真や観測地図ではありません）。
- 日食・月食の時刻は数分ずれることがあります。流星群の数は目安です。
- 星雲・星団の距離は代表的な値の目安で、形は模式図です。
- 大気による浮き上がり（地平線近くで約0.5度）は計算していません。

## 12. 困ったとき

- **起動すると「OpenGL 3.3 以上が必要」と出る**：グラフィックのドライバーを確認してください。
- **画面が暗い・何も見えない**：時間が昼（地上モード）になっていないか、「表示」メニューで表示が消えていないかを確認してください。
- **動作が重い**：「星の数」を減らす、「表示」メニューで銀河・クエーサー・たくさんの小惑星・系外惑星を消す、ウィンドウを小さくすると軽くなります。時間を止めているときは描き直さないので、パソコンの負担はほとんどありません。
- **ダウンロードがうまくいかない**：インターネットにつながっているか確かめてください。小惑星・彗星と系外惑星は、ブラウザーで保存したファイルから読み込むこともできます（10. を見てください）。
- **人工衛星の位置がずれている**：軌道のデータが古くなっています。「ファイル」からダウンロードし直してください。
- **表示の設定**（ウィンドウの大きさ、表示メニューの選択、星の数など）は、終了するときに保存され、次回の起動で元に戻ります。
